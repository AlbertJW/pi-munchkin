# Optimizer archive

This directory is retained as a **historical, unsupported measurement archive**. It is not part of
Pi Munchkin's default getting-started path. Keep the source, raw results, methodology,
preregistrations, and tests intact so the work remains auditable.

The 2026-07-27 audit found that most rounds could not support their recorded interpretation:
sample sizes were too small, pass/fail did not measure the efficiency target, and most candidates
could not prove their mechanism fired. Every pre-audit `NEUTRAL` remains recorded as history but
is currently **UNTESTED**, not rejected.

Read [`docs/MEASUREMENT_METHODOLOGY_2026-07.md`](docs/MEASUREMENT_METHODOLOGY_2026-07.md) and
[`docs/MOTHBALLED_2026-08-03.md`](docs/MOTHBALLED_2026-08-03.md) before running or citing anything.
Pass/fail is a harm guard; positive decisions require continuous effort measures, exposure
evidence, adequate power, an in-band task, and a single model-visible surface.

Restarting a gate round, adopting a candidate, or deleting optimizer material requires explicit
human approval.
