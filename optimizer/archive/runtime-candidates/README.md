# Retired runtime candidates

These files preserve the final source of candidates removed from the loadable
harness surface in the 2026-08 spiral-control retirement draft. They are audit
history, not package inputs, extension entries, active optimizer recipes, or
trusted instructions. Their imports and former environment switches are kept
for provenance; nothing under this directory is loaded automatically.

- `micro-gate.ts` and `micro-gate-policy.ts`: retired micro-gate and slop paths.
- `payload-audit.ts`: retired project-local provider-payload trace writer.

Recorded results, verdicts, methodology, and the repository's Git history remain
the authority for what these candidates did and how they were evaluated.
