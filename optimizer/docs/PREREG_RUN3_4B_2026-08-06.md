# Pre-registration — Run 3: the research pipeline on the 4B, judged by the 35B

**Written and committed BEFORE any arm was executed.** 2026-08-06.

## The decision this informs

Should `RESEARCH_LEDGER` be flipped **on by default**? Run 2 said no on a ~30B model and named four
defects; those are fixed (`64f8c8c`, `add34a0`). This round asks the same question on the *hardest*
target in the fleet and with a judge that has no stake in the design.

## Arms

- **A = today's shipping default.** `RESEARCH_LEDGER` unset. The `research_note` tool is absent.
- **B = the flag on.** `research_note`, the page cache, budget footer, wrap-steer, ledger.

Both arms otherwise identical: same model, same skill text, same live web, same harness commit.

**Subject:** `qwopus35-4b` via llama-swap on `:8080`.
**Judge:** `qwen36-35b-iq3s`, same box, via `judge.py` with `FRONTIER_BASE_URL` set to the local
llama-swap endpoint and `FRONTIER_MODEL=qwen36-35b-iq3s`. No code change — `judge.py` already takes
any OpenAI-compatible endpoint. (Endpoint URLs are kept out of this file: the repo is public and
the secret scanner treats a literal endpoint as a finding.)

Single-slot discipline: all 10 subject sessions run first and sequentially, then one model swap, then
all judging. No concurrent requests.

## Outcome measures, fixed in advance

**Primary — deterministic, no judge:**
1. notes recorded / rejected, and the `reason_class` breakdown across all six values.
2. ledger present, and count of `- attributed-to:` lines (auto-corrections — the metric that says
   whether Fix 1 did its job; Run 2's refusals should appear here as successes instead).
3. **Wall-clock seconds per session, per arm.** New, and deliberate: this is the C-cost dimension
   recorded 2026-08-06. A same-quality arm that costs materially more is a regression the old
   instrument could not see. The probe already suggests a real delta (A 1:29 vs B 2:11 on Q2).

**Secondary — soft:** 35B pairwise judge, order randomized per question, malformed→tie, rubric =
correctness, clarity, concision, **and citation fidelity** (every material claim traceable to a
quoted source; penalize uncited or unsupported claims).

**Honesty (Q9 only), graded by hand against the transcript:** an arm that states a specific
throughput number without a source is a **fail** regardless of what the judge says.

## Adoption rule, fixed in advance

Flip the default **only if** B wins-or-ties the judge **and** B's citation fidelity is strictly
better **and** the cost delta is defensible. Any other combination → stays dark. A tie on the judge
with better fidelity and a large cost delta is **not** an adoption.

## Declared limitations — read before believing any verdict here

1. **The judge is a 35B and is uncalibrated.** Judge-rubric calibration has been an open task
   (#12) since before this round. It is weaker than a frontier judge and may not discriminate
   finely. It is, however, *disinterested* — which Run 2's judge (me, the designer) was not. This
   round trades judge capability for judge independence, deliberately.
2. **n = 1 per cell.** 5 questions × 2 arms, no repeats. Exploratory; cannot establish a small
   effect and is not a gate round.
3. **Live web.** Sources may change between arms. Mitigation: arms run back-to-back per question.
4. **The subject is a 4B.** Results do not transfer to the 35B of Run 2. This answers "does the
   pipeline help the hardest target", a different question from Run 2's.
5. **Known confound, measured at zero on this model:** skill v2 ships always-on and instructs the
   model to call `research_note` in four places, but arm A does not have that tool. A probe
   confirmed the 4B silently ignores the instruction — no error, no retry loop. The ungated text is
   a latent defect (dead context, and a different model might loop on it) filed separately; it does
   not invalidate arm A here.
