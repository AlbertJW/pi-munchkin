# Optimizer archive

Superseded charters, plans, and procedures. Kept verbatim, current for nothing.

The measurement programme started, stopped, restarted, and stopped again between 2026-06 and
2026-08, and each transition was written down as its own charter. Read in isolation any one of
them will tell you the programme is in a state it left months ago — `MOTHBALLED_2026-08-03.md`
was superseded by `UNMOTHBALL_2026-08.md`, which was superseded by `MOTHBALLED_2026-08-21.md`,
which the Qwen 35B cohort has since overtaken in practice.

For the actual arc, read [`../PROGRAMME_HISTORY.md`](../PROGRAMME_HISTORY.md). For what has
actually been run, read [`../SCREENS.md`](../SCREENS.md). For the rules those runs were held to,
read [`../MEASUREMENT_METHODOLOGY_2026-07.md`](../MEASUREMENT_METHODOLOGY_2026-07.md), which is
still current.

`HARNESS_SELF_IMPROVEMENT.md`, split at its own section seam on 2026-09-03. The second half is
still live and still appended to, as [`../ROUND_LEDGER.md`](../ROUND_LEDGER.md). Neither half
