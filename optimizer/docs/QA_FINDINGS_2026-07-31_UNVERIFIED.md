### [medium/INSTRUMENT] real_gate.sh reads subscores from a model-writable path, lexicographically-first, with no provenance check
- **where**: `optimizer/real_gate.sh:876` (measurement-integrity)
- **claim**: The grade artifact is located by globbing the session's own workdir for `.*-grade.json` and taking `sorted(...)[0]`. $wd is the directory the model worked in for the whole session, and the post-session anti-tamper step only restores `test/*.test.js` — nothing else in the workdir is sanitized. So any file matching `.<name>-grade.json` that the model left behind is eligible, and a name sorting before `.audit-grade.json` (e.g. `.a-grade.json`) is selected in preference to the real grader's output. The grader itself writes with a relative path from cwd=$wd (audit-sweep.test.js:71 `writeFileSync(".audit-grade.json", ...)`, run via real_gate.sh:761 `( cd "$wd" && node --test )`), so it can only overwrite its own exact filename.
- **evidence offered**: optimizer/real_gate.sh:876 (`_hits=sorted(_glob.glob(os.path.join(workdir, ".*-grade.json")))`) and :877-881 (`_hits[0]` is read and trusted); real_gate.sh:450 (fixture tar'd into $wd), :477 (`config.py --apply --workdir "$wd"`), :761 (gate runs with cwd=$wd) — $wd is the model's working directory; real_gate.sh:751-759 (the anti-tamper block removes and restores only `"$wd"/test/*.test.js`); real-gate-fixtures/hidden/audit-sweep.test.js:71; effort_report.py:25-39 and :140 (subscores becomes the leading metric under --graded). Contrast real_gate.sh:471-475, which keeps context telemetry in an unlinked fd with an HMAC precisely so "evaluated tool subprocesses ... cannot open, truncate, replay, or forge the evidence by pathname" — the subscores channel is exactly that pathname-forgeable channel.
- **claimed impact**: A session that writes `.a-grade.json` containing {"fixed":8,"total":8} into its workdir gets subscores 8/8 on its row regardless of what the hidden grader computed, because `.a-grade.json` sorts before `.audit-grade.json` and only `_hits[0]` is read. Under `effort_report.py --graded` that is the primary outcome of the round, so a candidate arm could show a large graded_rate improvement with no real work. I could NOT confirm a path by which the model learns the filename pattern — the fixture root and prompt contain no reference to it (grep for 'grade' under real-gate-fixtures/audit-sweep/ is empty) — so this is an open hole rather than a demonstrated exploit. It is also a plain robustness bug: multiple artifacts are resolved by lexicographic accident rather than by contract.
- **proposed fix**: Pin the artifact name per fixture in the manifest (e.g. `"grader": {"artifact": ".audit-grade.json"}`) and read exactly that path instead of globbing, or delete every `.*-grade.json` in $wd immediately before the anti-tamper restore at real_gate.sh:751 so only the grader's own post-session write can exist. Refuse (rather than silently pick one) when more than one artifact matches, and record `subscores.source` against the manifest-declared name in the row so a mismatch is auditable.
