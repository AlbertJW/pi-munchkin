The governed pilot registry is
`optimizer/v2/benchmarks/g03-representative-pilot-v1.json`. It contains twelve
immutable cases: two coding edits, two failure-recovery tasks, two documentation
tasks, two long-context tasks, and four research shapes (comparative, contested,
multi-part, and lightweight fact lookup). Every case binds a split, fixture
digest, admission-receipt digest, local oracle, timeout/resource limits, and an
isolation receipt. Train and development contain ten cases; the two research
cases in the opaque test split are never evaluated by the offline runner.

`optimizer/v2/examples/g03-baseline-preregistration.json` freezes the Qwen 35B
adoption cohort (`local-llamacpp/qwen36-35b-iq3s`), baseline and candidate
configuration hashes, the source and loaded-surface identities, seeds,
repetitions, deterministic arm randomization, timeouts, resource limits, and
development/test quarantine. Ling is intentionally absent: it remains a
protocol-qualification subject, not an adoption cohort.

The implementation in `optimizer/v2/benchmark.py` validates split disjointness,
fixture uniqueness, artifact/admission hashes, executable oracle containment,
isolation receipts (including safe relative allowlists), taxonomy counts, and
protocol limits. The deterministic oracle in
`optimizer/v2/oracles/baseline_shape.py` accepts only a redacted trial summary
and checks artifact persistence, verification, evidence coverage, source
binding, and stop classification without reading prompt or answer content.

`optimizer/v2/baseline.py` provides the no-inference preparation and baseline
protocol runner. It emits paired `(case, seed, repetition, arm)` cells,
per-case outcomes, cohort summaries, hard-guard counters, and secondary costs
(tool calls, retries, wall time, input/output tokens, and compactions). Child
telemetry is labelled `unavailable-contained`, never zero. A complete case
coverage ledger records each evaluated case and each opaque-test exclusion with
an explicit reason. Development payloads are marked quarantined, optimizer
diagnosis access is forbidden, and no opaque test payload is opened. Reports
are content-addressed and can be written to a private directory with atomic,
permissioned writes; the reconstruction receipt includes every fixture,
admission, oracle, and isolation digest plus the exact offline command.

`optimizer/v2/real_baseline.py` is the fail-closed bridge for a future real
screen. It ingests only fresh `pi.eval-row/v4` rows and exact trial-validity
sidecars, binding each row to the frozen pack/preregistration, authenticated
parent provenance, arm exposure, stable serving identity, and resolved subject
model. It emits a redacted private report, normalizes the legacy one-repetition
`real_gate.sh` seed shape, and retains missing, malformed, duplicated, or
mismatched cells as explicit non-authoritative classifications. Its `--ingest`
mode is artifact-only and never launches Pi or a model.

`optimizer/v2/research_baseline.py` closes the research-shaped half of that
contract. A parent-owned private `pi.research-trial/v1` artifact is strict about
fixture identity, arm/model/config/surface/serving provenance, graph settlement,
bounded discovery usage, and original (non-Jina) source URLs. The adapter sends
only claim IDs, admitted source metadata, and parent-validation flags to the
metadata-only research oracle, then emits the same redacted V4 row and validity
pair consumed by `real_baseline.py`. Invalid plans and oracle infrastructure
errors remain non-authoritative; a valid citation miss is a scored zero. The
`--reduce` command writes private row files and never launches Pi or a model. It
also rechecks the frozen pack file hash and each research fixture's admitted
content digest at reduction time, so a same-shaped but edited fixture cannot
be scored as the original case.

`optimizer/v2/research_runner.py` is the corresponding parent recording boundary.
It validates one train/development research cell against the frozen pack and
preregistration, normalizes the bounded process and serving observations, and
records only a private `pi.research-trial/v1` artifact. Its `--prepare` mode
also creates a deterministic, prompt-free `pi.g03-research-cell-plan/v1` for
the non-opaque research cells, binding task IDs, arm order, fixture/config/
surface digests, and private artifact paths before execution. The parent
supplies a strict metadata-only `pi.research-parent-report/v1` summary; missing
or malformed reports become explicit non-authoritative attempts with zero
accepted research usage, rather than silently becoming passing rows. Publication
is atomic, permissioned, idempotent, and contained by a private run root; an
explicit symlink run root or symlinked destination component is rejected. This
module never launches Pi, reads answer text, or invokes a model; an explicitly
approved parent runner can call `record_research_artifact` after its child exits,
then invoke the existing `research_baseline.py --reduce` command.
The current r2 task bindings are versioned in
`optimizer/v2/examples/g03-research-task-map-r2.json`; they contain only
bounded task IDs and no prompt or answer content.

`research_baseline.py --reduce-plan` validates the complete prepared plan,
reduces every present private receipt through the same metadata-only oracle,
and returns explicit `missing_cells` for receipts that were never published.
It rejects run, case, arm, seed, configuration, surface, and experiment drift
before returning any partial result; its optional bundle output is also offline
and private.

The full train/development case-to-real-gate task binding is now versioned at
`optimizer/v2/examples/g03-baseline-task-map-r2.json` (canonical mapping digest
`856d57e09ddc2a93ef4076395ee184777c14d8256f23bfa726a77d490b53f0ae`). The real
baseline ingestor records that digest in the redacted report and rejects
symlinked map files, closing a reconstruction gap without changing the frozen
pack or executing a model.

The real report also records the private run identity and semantic JSONL
receipts (schema, count, and canonical digest) for the exact ordered row and
trial-validity inputs. `real_baseline.py --verify` validates those receipts and
rebuilds the report from the private inputs without rerunning inference; a
changed row or sidecar fails closed.

Complete authoritative reports now aggregate `unsupported_claims` and
`unwanted_continuation` at both cohort and overall hard-guard level. If any
required guard value is missing or the cohort is incomplete, the aggregate
stays explicitly unavailable instead of being reported as zero.

`optimizer/v2/g03_readiness.py` (commits `d6c7648`, `297702a`) now provides a read-only host preflight that
binds the r2 source/loaded surfaces, task-map digest, and requested Qwen member.
On 2026-09-07 it reached the live router (`health_ok=true`) and correctly
returned `ready=false, model_state=unloaded`; it never sent a chat request.

The complete eight-case non-research execution slate was also accepted by
`real_gate.sh --dry` with the r2 baseline/candidate configs and two registered
seed cells. The host-context dry output bound the explicit Qwen request and
reported `state=unloaded`; it created no rows and loaded no model.

`optimizer/v2/g03_reissue.py` provides the safe next-step bridge for the stale
live identities. It validates the frozen pack and preregistration first, then
publishes a revision-specific pair with explicitly supplied source and loaded
surface hashes, a recomputed pack file digest, and repository-contained atomic
writes. It refuses malformed identities, symlink traversal, output escapes, and
overwriting the frozen inputs. The utility is artifact-only; it does not select
a model, start Pi, or run inference.
